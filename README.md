# Bickr

Bickr is a blockchain-based sports prediction platform concept focused on competitive picks, peer challenges, and sports debates. It aims to bring participants together around sporting events while using smart contracts to support transparent, automated on-chain interactions.

## Overview

Bickr is designed around three core experiences:

- **Sports predictions:** Participate in predictions related to sporting events.
- **Peer challenges:** Challenge other participants and compare predictions.
- **Sports debates:** Discuss competing views and make sports conversations more interactive.

The project's stated goal is to use blockchain transactions and smart contracts to make supported interactions more transparent. Network, contract, and deployment details should be confirmed from the project's technical documentation before using the platform with funds.
